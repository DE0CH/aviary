# The Secrets of YYC AI (namespaces yyc-ai, yyc-ai-fabric on YYC's Talos cluster) that live in git, sealed into
# yyc/deploy/sealed, and the store `yyc` keys their values come from. DE0CH/yyc-code's infra/seal.py seals and checks
# them with --root (this repository) and --map (this file), with the Talos cluster's cert:
#   python3 <yyc-code>/infra/seal.py --root . --map yyc/secrets.txt NS/NAME     (a session holding the store `yyc`)
#
# NAMESPACE/NAME  TYPE  FILE  KEY=STORE_KEY ...      (STORE_KEY+nl: the store value followed by one newline)
#                                                    ('text': that literal text, not a store key)
#                                                    (A|B?: "<A>,<B>", the parts joined by commas; a trailing ? makes a
#                                                     part optional, skipped when the env lacks it: a callee accepting
#                                                     the current and the next pair token during a rotation)
# Pair tokens (spec-platform 3.7): <CALLER>_TOKEN_<CALLEE> = <CALLEE>_ACCEPT_<CALLER>, store key YYC_TOKEN_<CALLER>_<CALLEE>.
